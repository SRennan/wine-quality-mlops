# Wine Quality MLOps

## Descripcion
Proyecto de Machine Learning para predecir la calidad del vino mediante sus propiedades fisicoquimicas.

## Objetivo
Desarrollar un sistema de prediccion utilizando Machine Learning e implementar un flujo MLOps que incluya experimentacion, versionado, contenerizacion, despliegue y monitoreo.

## Dataset
Wine Quality Dataset - UCI Machine Learning Repository.

## Tecnologias
- Python
- Scikit-learn
- MLflow
- Docker
- Kubernetes
- FastAPI
- Git y GitHub
